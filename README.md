# Scrapbook
<p align="justify">Scrapbook started as a simple project to make it easier to non-destructively copy-paste images onto a canvas. Compared to Paint, which flattens images into a single bitmap, or something like Photoshop, which is a bit too heavy for what I needed. However, as I iterated on the idea I wanted to expand the project into an art-making tool. Combining image assets with GPU compute shader technology to make unique artworks. In its current state, the application can add images, has undo/redo functionality, save and load project files, and exposes board element properties for the user to manage.</p>
